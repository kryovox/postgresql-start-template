# Ф04 / КТП04 — первый шаг проекта

Время: примерно 15–20 минут. Используйте предметную область из этапов 1–2 предыдущих занятий.

В [project_start.md](../project/project_start.md):

1. Перечислите ядро из 3–5 сущностей.
2. Выберите одну будущую таблицу.
3. Опишите 2–3 первых поля: имя, смысл, тип integer или text.
4. Приведите три примера будущих строк.
5. В двух предложениях укажите ближайшие границы ядра и одно уточнение для выбранной таблицы.

Для платформы курсов возможны студенты, курсы, уроки и записи на курсы. Для другой предметной области выберите подходящие объекты.

Ориентир — 10–15 строк текста и небольшая таблица. Исходные этапы сохраните рядом с материалами проекта. Аудиторный lesson04.sql остаётся в папке практики; для его хранения в комплекте проекта можно использовать ссылку на этот файл.

Создание таблицы собственного проекта продолжим на следующей паре. После выполнения добавьте короткую строку в [журнал проекта](../project/report.md).
