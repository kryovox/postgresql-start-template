# Практика 01 Первый SQL-запрос

Стартовая работа для знакомства с PostgreSQL, выполнением запросов
и сохранением SQL в GitHub. Выполняйте её в порядке, указанном преподавателем.

1. Настройте среду по [инструкции](../../docs/SETUP.md).
2. Откройте и выполните [`main.sql`](main.sql) в своей учебной базе.
3. Выполните задания из [`tasks.md`](tasks.md).
4. Заполните [`report.md`](report.md).
5. Отправьте SQL-скрипт, отчёт и учебные данные при их использовании в свой репозиторий.

Начальный запрос выводит `Hello, PostgreSQL!`.
Команда запуска из корня репозитория при настроенном psql:

```bash
psql -h localhost -U YOUR_USER -d YOUR_DATABASE -f practice/01-first-sql/main.sql
```

Замените `YOUR_USER` и `YOUR_DATABASE` своими параметрами.
В pgAdmin 4 используйте Query Tool и кнопку **Execute**.
