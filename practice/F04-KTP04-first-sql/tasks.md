# Задания Ф04 / КТП04

1. Выполните `SELECT 2 + 3;`, проверьте результат 5.
2. Создайте `lesson04_courses`: `course_id integer`, `title text`, `duration_hours integer`.
3. Прочитайте все столбцы пустой таблицы.
4. Добавьте курс 1 — «Основы Python», 24 часа. Проверьте одну строку.
5. Одной командой добавьте курсы 2 — «Веб-дизайн», 18 часов, и 3 — «Робототехника», 30 часов. Проверьте три строки.
6. Получите только course_id и title. Затем самостоятельно выберите title и duration_hours, после этого один title.
7. Самостоятельно добавьте курс 4 — «Разработка игр», 16 часов. Проверьте состав четырёх строк и нужные столбцы.
8. Дополнительно добавьте придуманный курс 5.
9. Сохраните SQL. Заполните notes.md: назначение трёх команд, проверка данных и одна ошибка либо описание проверки без ошибок.

Порядок строк при SELECT без сортировки может различаться. Сверяйте значения строк. На этой паре одинаковые номера ещё разрешены. Непредвиденные дубликаты покажите преподавателю.
