# Ф04 / КТП04 — первые команды SQL

[Конспект](../../lectures/F04-KTP04-first-sql.md) · [Условия](tasks.md) · [Заготовка SQL](lesson04.sql) · [Пояснения](notes.md)

Откройте lesson04.sql в Query Tool своей учебной базы. Для первого выполнения таблица `lesson04_courses` должна отсутствовать. Записывайте команды по ходу занятия и выполняйте выбранные фрагменты.

Основная работа: одна таблица, четыре курса, выбор всех и выбранных столбцов. Дополнительная часть: пятый курс. В начале используются только integer, text, CREATE TABLE, INSERT INTO и SELECT.

Первичный ключ на этой паре ещё не задаётся. Повторный INSERT способен добавить одинаковые строки. Для просмотра выполняйте нужный SELECT.

Сдайте заполненные lesson04.sql и notes.md в своей копии репозитория. Условия первого запуска и ошибки фиксируйте кратко. Полный запуск повторяется в отдельной пустой учебной базе.
