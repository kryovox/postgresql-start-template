## Первые шаги

1. Создать свой репозиторий кнопкой **Use this template → Create a new repository**.
2. Назвать его `postgresql-start` и заполнить карточку выше.
3. Клонировать репозиторий на компьютер и настроить среду по [инструкции](docs/SETUP.md).
4. Открыть [первую практику](practice/01-first-sql/README.md), выполнить SQL-скрипт и проверить результат.
5. Сохранить работу коммитом и отправить изменения на GitHub.

Подробный порядок с GitHub Desktop и Git — в [начале работы](docs/START.md).

## Как выполнить первый SQL-скрипт

В pgAdmin 4 выберите свою учебную базу, откройте **Query Tool** и загрузите файл
[`practice/01-first-sql/main.sql`](practice/01-first-sql/main.sql). Выполните запрос.
Пошаговая настройка — в [SETUP.md](docs/SETUP.md).

При настроенном клиенте psql из корня репозитория:

```bash
psql -h localhost -U YOUR_USER -d YOUR_DATABASE -f practice/01-first-sql/main.sql
```

Замените `YOUR_USER` и `YOUR_DATABASE` своими параметрами подключения.
При использовании другого учебного сервера следуйте инструкции преподавателя.
