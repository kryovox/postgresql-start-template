# Копия курса на Google Drive

Источник материалов: `kryovox/postgresql-start-template`, ветка `main`.

[Папка объединённой группы](https://drive.google.com/drive/folders/1YTC-Jt9m-JXu6tpWondBzVQ7tpqJ3sxs)

На Drive создана структура с теми же относительными путями и именами файлов. Первоначальная копия включает все файлы шаблона, включая `.github/`, Markdown, SQL и DOCX. Служебный каталог Git `.git/` существует только в локальной копии Git и в содержимое репозитория не входит.

`drive-map.json` содержит ID корневой папки и соответствия каталогов. Это карта для следующего этапа настройки репликации. Ключи доступа в ней отсутствуют.

Постоянная автоматическая репликация пока не подключена. На следующем этапе нужно выбрать способ авторизации Google Drive и запуск переноса из основного репозитория. Студенческие копии используют собственные файлы и к папке преподавателя запись не получают.

Рекомендуемый режим: перенос файлов по относительным путям с обновлением существующего файла по его Drive ID; новые каталоги добавляются по мере появления. Удаление или перенос существующих материалов включается отдельно после проверки правил. Файлы SQL и Markdown сохраняются в исходных форматах. Общие права доступа к папке назначает преподаватель.
