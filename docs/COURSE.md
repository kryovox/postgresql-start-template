# Маршрут дисциплины

ОП.08 «Основы проектирования баз данных». Совместные занятия групп 11/1-РПО-26/1 и 9/2-РПО-25/3. Общий объём дисциплины — 68 академических часов, 34 пары.

Первые три пары: начальные понятия БД, знакомство с pgAdmin и черновое описание предметной области. Самостоятельную запись SQL начинаем на фактической паре 4.

| Фактические пары | Содержание |
|---|---|
| 4–9 | Первые команды SQL, типы, ключи, связи, ограничения, заполнение, выборки и изменение данных |
| 10–14 | Нормализация и проверка физической схемы |
| 15 | Изменение структуры через ALTER TABLE |
| 16–17 | Закрепление SELECT и DML |
| 18–23 | JOIN, подзапросы, группировка, CTE, оконные функции, представления |
| 24–30 | Индексы, транзакции, параллельная работа, права, восстановление, импорт, миграции |
| 31–34 | Проверка, доработка, воспроизведение и защита базы |

Точный порядок уточняет преподаватель при согласовании рабочего плана с кафедрой. Название пары содержит фактический номер и опорный номер КТП. Другие затронутые позиции указаны в конспекте.

## Накопительный проект

Выберите ядро из 3–5 осмысленных таблиц в своей предметной области. После каждой изученной темы добавляйте небольшой проверяемый фрагмент. Предметная область сохраняется из этапов 1–2. Для платформы курсов возможное ядро: студенты, курсы, уроки, записи на курсы. Состав проекта согласуется с преподавателем.
