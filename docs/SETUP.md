# PostgreSQL и pgAdmin 4

Для первых занятий используются PostgreSQL и pgAdmin 4. Установка дополнительных сред программирования пока не требуется. В аудитории используйте подготовленное преподавателем подключение.

## Подключение

1. Запустите pgAdmin 4. В дереве слева раскройте **Servers** и выбранный сервер.
2. При запросе введите свой локальный пароль. Если подключение ещё не создано, согласуйте с преподавателем адрес сервера, порт, пользователя и учебную базу.
3. Раскройте **Databases**, найдите свою учебную базу. Проверьте её имя перед запуском команд.
4. Нажмите на базу правой кнопкой и выберите **Query Tool**.
5. Выполните `SELECT 2 + 3;`. В **Data Output** ожидается число 5.

Для домашней установки используйте официальные страницы: [PostgreSQL](https://www.postgresql.org/download/) и [pgAdmin](https://www.pgadmin.org/download/). Версию и способ установки согласуйте с преподавателем. Пароль, выбранный при установке сервера, понадобится при подключении.

## Работа в Query Tool

- Редактор содержит SQL-команды; для выполнения отдельного фрагмента выделяйте его.
- Кнопка **Execute / Execute script** запускает выделение; при отсутствии выделения может выполняться весь текст. Сверяйте подсказку кнопки в своей версии.
- **Data Output** показывает результат выборки, **Messages** — сообщения сервера.
- Для первой работы оставьте **Auto commit** включённым.
- После создания таблицы обновите **Schemas → public → Tables** через **Refresh**. При другом имени рабочей схемы используйте схему, указанную преподавателем.
- Откройте стартовый `lesson04.sql` из папки практики и сохраняйте изменения кнопкой **Save**.

## Если возникла ошибка

Сначала прочитайте Messages. Затем проверьте выбранную базу, имя таблицы, запятые и кавычки. Повторное CREATE TABLE сообщает о существующей таблице. Повторный INSERT в первой работе может добавить дубликаты. Для просмотра данных выполняйте SELECT. Сохраните текст ошибки и короткое пояснение в notes.md.

SQL-файлы воспроизводят действия в подготовленной базе. Для повторного запуска всей первой работы требуется отдельная пустая учебная база. Проверяйте это с преподавателем.
