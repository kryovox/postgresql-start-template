# Настройка среды PostgreSQL

Для выполнения работ нужны сервер PostgreSQL, SQL-клиент pgAdmin 4 и средство
работы с Git. Параметры учебного сервера и базы уточните у преподавателя.

## pgAdmin 4 на Windows

1. Если сервер ещё не подготовлен, установите PostgreSQL с [официального сайта](https://www.postgresql.org/download/).
   pgAdmin 4 доступен также на [официальной странице](https://www.pgadmin.org/download/).
2. Откройте pgAdmin 4. В дереве **Servers** выберите сервер или зарегистрируйте
   подключение с адресом, портом и пользователем, указанными преподавателем.
3. Подключитесь, раскройте **Databases** и выберите свою учебную базу.
4. Нажмите на базу правой кнопкой и выберите **Query Tool**.
5. Откройте файл `practice/01-first-sql/main.sql` из своей локальной копии репозитория.
6. Выполните запрос кнопкой **Execute** и прочитайте результат в **Data Output**.

SQL-файлы сохраняются в репозитории. Таблицы и их данные находятся на сервере
PostgreSQL; они появляются после выполнения соответствующих SQL-команд.
Перед запуском проверяйте имя подключённой базы. Для первых упражнений
оставьте **Auto commit** включённым.

## Клиент psql

Этот вариант подходит, если psql установлен и доступен в терминале.
Параметры подключения должны соответствовать вашему учебному серверу.
При первой настройке следуйте инструкции преподавателя.

Проверьте доступность клиента:

```bash
psql --version
```

Откройте корень своего репозитория. В терминале выполните первый скрипт:

```bash
psql -h localhost -U YOUR_USER -d YOUR_DATABASE -f practice/01-first-sql/main.sql
```

Замените `YOUR_USER` именем пользователя PostgreSQL, `YOUR_DATABASE` — именем
своей учебной базы. Для другого сервера замените `localhost` его адресом.
Пароль вводится по запросу клиента.

Ожидаемый результат стартового файла — столбец `message` с одной строкой:

```text
Hello, PostgreSQL!
```

## Частые затруднения

| Ситуация | Что проверить |
|---|---|
| `psql` не найден | Установку клиента, PATH и перезапуск терминала |
| Не удаётся подключиться | Работу сервера, адрес, порт, пользователя и пароль |
| База не найдена | Правильность её имени и доступ к учебному серверу |
| Ошибка синтаксиса | Место ошибки, кавычки, скобки и точку с запятой |
| Выполняется старый текст | Файл сохранён и в Query Tool открыт нужный скрипт |
| Запрос выполняется в другой базе | Имя активного подключения в Query Tool |

Сначала добейтесь выполнения стартового файла, затем изменяйте его по заданию.
