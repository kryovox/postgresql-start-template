# Как сохранять и сдавать работы

Каждая работа размещается в папке с её номером. После пары Ф04 / КТП04 сохраните:

- `practice/F04-KTP04-first-sql/lesson04.sql` — выполненные команды;
- `practice/F04-KTP04-first-sql/notes.md` — три коротких ответа и результат проверки;
- `homework/project/project_start.md` — домашний шаг проекта.

В инструкциях README.md и tasks.md описаны условия работы. Ответы записывайте в отведённые файлы. Корневой README.md содержит вашу карточку и личный прогресс.

## SQL

Используйте понятные имена латинскими буквами с подчёркиваниями. Сохраняйте файлы в UTF-8. Разделяйте команды точкой с запятой. В комментариях указывайте назначение фрагментов. Для данных используйте вымышленные примеры.

В начале файла отметьте номер пары и условия первого запуска: имя учебной базы задаёт преподаватель; таблица первой практики ещё отсутствует. Во время повторной проверки выделяйте нужные SELECT. Схема, данные и запросы проекта будут дополняться после изучения соответствующих приёмов.

## Короткое пояснение

Достаточно 2–4 предложений о выполненном действии и проверке. При ошибке сохраните её текст и исправление. Скриншот добавляйте по условию задания или для объяснения результата; храните его в подпапке `screenshots/` соответствующей работы.

## Сдача

1. Сохраните файлы в своей локальной копии.
2. Выполните Commit с понятным сообщением и Push origin.
3. Проверьте файлы на GitHub.
4. Передайте ссылку на папку работы или конкретный коммит способом, указанным преподавателем.

Домашний проект развивается короткими шагами примерно на 15–25 минут. Первый шаг рассчитан на 15–20 минут. Сохраняйте ранние этапы локально; при необходимости добавляйте их в репозиторий с учётом персональных данных.
