# Оформление и сдача работ

## Куда сохранять

| Вид работы | Путь | Пример |
|---|---|---|
| Практика на занятии | `practice/NN-topic/` | `practice/01-first-sql/main.sql` |
| Домашнее задание | `homework/NN-topic/` | `homework/01-tables/main.sql` |
| Контрольная | `exams/exam-NN/` | `exams/exam-01/main.sql` |
| Тест | Папка, указанная преподавателем | `exams/quiz-01/report.md` |

Номер и имя папки берите из выданного задания. Примеры путей в этой инструкции
показывают формат; перечень выданных работ находится в README соответствующей папки.

В папке работы хранятся SQL-скрипты, необходимые входные данные и отчёт
`report.md` по требованию задания. Для нескольких самостоятельных задач
используйте `task-01/main.sql`, `task-02/main.sql` и отдельные учебные таблицы
или базы по условию работы.

## Имена и код

- Папки: две цифры номера, латиница, маленькие буквы и дефис: `02-tables`.
- Главный SQL-файл: `main.sql`; дополнительные скрипты называйте по назначению.
- Отчёт: `report.md` рядом с решением.
- Отступы: четыре пробела; таблицы и столбцы называйте по их назначению.
- В отчёте укажите способ запуска и результат проверки SQL-скрипта.

Файлы `.sql`, учебные `.csv`, схемы и необходимые пояснения отправляются на GitHub.
Локальные данные сервера, резервные копии и кэш редактора исключаются через
`.gitignore`. Пароли и токены храните отдельно от репозитория.

## Как назвать коммит

| Изменение | Пример сообщения |
|---|---|
| Начало практики | `practice 01: добавлен первый запрос` |
| Исправление | `practice 01: исправлена строка запроса` |
| Домашнее задание | `homework 01: создана таблица товаров` |
| Контрольная | `exam 01: выполнен вариант 2` |
| Оформление портфолио | `profile: добавлена лучшая работа` |

Сообщение должно объяснять изменение. По мере работы делайте небольшие
содержательные коммиты. Для начального этапа курса достаточно ветки `main`.

## Проверка перед отправкой

- [ ] Файлы сохранены в папку выданного задания.
- [ ] SQL-скрипт выполняется в нужной учебной базе.
- [ ] Проверены примеры из условия и ожидаемые результаты запросов.
- [ ] Я могу объяснить написанный SQL.
- [ ] Отчёт заполнен, если он требуется.
- [ ] В коммит входят SQL-скрипты и необходимые учебные данные.
- [ ] Выполнен **Push origin**; изменения видны на GitHub.

Передавайте преподавателю ссылку на папку конкретной работы.
Статус проверки и оценку сообщает преподаватель.
