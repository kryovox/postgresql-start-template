# Обновление материалов

Преподаватель ведёт исходный шаблон `kryovox/postgresql-start-template`. В студенческих копиях подготовлен ручной workflow **Обновление материалов курса**.

Исходный шаблон открыт для чтения. Workflow получает его без дополнительного токена через публичный Git URL. Автоматического расписания в шаблоне нет; запускайте получение материалов вручную перед занятиями.

## Получение материалов

1. Откройте **свой** репозиторий → **Actions**.
2. При предложении GitHub включите workflows в своей копии.
3. Выберите **Обновление материалов курса → Run workflow** на основной ветке.
4. Дождитесь успешного завершения и прочитайте сводку изменений.
5. В GitHub Desktop отправьте свои текущие изменения и выполните **Fetch origin → Pull origin**.

В исходном репозитории преподавателя перенос пропускается.

| Пути | Правило |
|---|---|
| `docs/`, `lectures/`, `materials/`, `assets/` | Получают актуальные материалы преподавателя |
| `.gitignore`, `.gitattributes`, `.editorconfig` | Обновляются |
| Общие README разделов, README.md и tasks.md непосредственно в папках заданий | Получают актуальные условия |
| Новые заготовки SQL и отчётов | Добавляются, если файла по такому пути ещё нет |
| Существующие SQL, notes.md, report.md, project_start.md и файлы проекта | Сохраняются |
| Корневой README.md и `.github/` | Сохраняются |

Удаление файлов при обновлении не выполняется. Личные заметки сохраняйте в файлах для ответов. Если стартовый SQL уже существует, обновление сохранит его; преподаватель отдельно сообщит об исправлении заготовки.

Workflow выполняет `git push` от GitHub Actions. Если правила вашей копии запрещают запись или ветка изменилась одновременно, сохраните работу и обратитесь к преподавателю. Пароли PostgreSQL и дополнительные токены для этого публичного режима не требуются.
