# Начало работы

1. Войдите в свой GitHub. Откройте репозиторий преподавателя и выберите **Use this template → Create a new repository**. Доступ к закрытому шаблону предоставляет преподаватель.
2. Создайте репозиторий `database-course` в своём аккаунте. Если он закрытый, согласуйте доступ для проверки с преподавателем.
3. В GitHub Desktop выполните **File → Clone repository**, выберите свой репозиторий и папку на компьютере.
4. Откройте эту папку в редакторе. Заполните карточку в корневом README.md.
5. Откройте pgAdmin и проверьте подключение по [SETUP.md](SETUP.md).
6. Откройте нужную работу в [разделе практики](../practice/README.md) и сохраните её файлы в соответствующей папке.
7. В GitHub Desktop проверьте список изменений, введите сообщение `Выполнена практическая работа`, нажмите **Commit to main**, затем **Push origin**.
8. Откройте свою копию на GitHub и убедитесь, что файлы доступны. Передайте преподавателю ссылку на выполненную работу.

Git хранит ваши SQL-файлы. После открытия SQL в Query Tool подключитесь к нужной базе и выполните команды. Содержимое базы сохраняется сервером PostgreSQL отдельно от файлов репозитория.

При использовании Git в терминале выполняйте команды из папки своей копии:

```bash
git status
git add .
git commit -m "Выполнена практическая работа"
git push
```

На чужом или общем компьютере завершайте сеанс GitHub после работы. Параметры подключения и пароли храните локально.
